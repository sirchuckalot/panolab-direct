# Native TNP protocol observations

Evidence: historical static analysis, original protocol patent, and physical transactions. Version 1. UDP source 8320, destination 8321. No host network or privileged sockets needed for directed unicast inside the tested rootless container. A subnet broadcast yielded no candidate, cause unresolved. Connectionless configuration reads produce a 16-byte request and 20-byte data response; 8-byte transport acknowledgement is not data. Header has 12-bit sequence and acknowledgement, 24-bit timestamp. Endpoint header is a big-endian 16-bit field, five endpoint bits and eleven length bits. Register responses must match source, operation, address and transaction ID.

Connection-oriented transport supported ordinary CSR reads where the connectionless path only acknowledged. Zero initial sequence worked; randomized sequence failed strict correlation. Session changes peer state transiently; normal own-session closure returned peer to zero. Observed response flags: connectionless 0x08/0x48, stream 0xc3/0x43/0x53. Low flag meanings are unresolved. No session takeover or general reset operations. See [register map](REGISTER_MAP.md).

The qualified acquisition algorithm preserves ordered selection/data retrieval, batches at most 72 ordered word operations, validates responses and acknowledges cumulatively every 16 packets. No native auto-increment was observed for repeated reads of the selected data register. Strict sequence and transaction matching, bounded deadlines, stop on ambiguity, normal close and idle recheck. No general-purpose programming, flash erase or protection commands. Detailed implementation in tools; private original captures retained by owner. This is not a full TNP specification or proof of security.
